# Fragalysis PG-Vector DB image

![GitHub Release](https://img.shields.io/github/v/release/xchem/fragalysis-database)

A project that adds [pgvector] to the otherwise standard PostgreSQL
database cartridge we use with Fragalysis.

## Building the image
The image is built using the GitHub release action, which runs
when we make a *Release*.

---

[pgvector]: https://github.com/pgvector/pgvector
